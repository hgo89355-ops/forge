# Growth plan — goal: a few million views per video (owner, 2026-11-24, "willing to be patient")

## Where the millions come from in this niche (vidIQ data)
- Zack D. Films-style character stories on everyday mechanisms: 16.5M (keys), 26.4M (ink tags).
- Small channels break out *after* volume: the under-5K-sub channels with 100K–3.4M hits had usually posted many
  Shorts first. A single video is a coin flip; 100 videos are a strategy.

## The plan
1. **Volume first (months 1–3):** 1 Short per day once the pipeline is fast (target: script → render in < 2 h,
   render ~40 min). Long videos: 1 per week, built from the Shorts' machines.
2. **Pick topics only from proven outliers:** every topic must have a ≥ 10x outlier in the last year; avoid crowded
   topics (the lock topic had 14 copies in 7 weeks); prefer "everyday thing + hidden mechanism + a person in trouble".
3. **Same proven skeleton every time:** stickman in trouble at 0.0 s → "the reason is hiding inside" → colour-coded
   cutaway → payoff → twist → loop. 25–35 s. Change the story, never the skeleton (until data says otherwise).
4. **Measure and double down (from video ~10):** connect the channel to vidIQ for analytics (owner step). Watch
   "viewed vs swiped away" (aim > 70%) and average % viewed (aim > 90%, loops push it over 100%). Make follow-ups
   of anything that beats the channel average 3x; drop formats that lose in the first 2 seconds.
5. **Series and recurring character:** the same stickman with running jokes (always using the wrong key, always
   getting bonked) so viewers recognise him; "Part 2" Shorts for hits.
6. **Packaging tests:** 2–3 title ideas per video; vidIQ title scoring when credits allow (5 credits each).

## Honest milestones (typical for faceless Shorts channels, not a promise)
- First 30 Shorts: mostly 1K–20K each; 1–3 videos break 100K.
- Months 2–4: if the format fits, regular 100K+ videos and the first 1M+.
- "Millions per video" consistently: usually after 100+ uploads and several months of tuning.

## Remakes (owner idea, 2026-11-25)
Re-post a topic weeks later as a **remake, not a copy**: change the first 2 seconds (hook), the title and at least one
big visual element (character action, story twist); keep the original up; wait 4–8 weeks; change one main thing per
remake so we learn what moved the numbers. Never re-upload near-identical files — YouTube's "reused/repetitious
content" rules can block monetisation later. Best candidates: videos that did well (proven topic) or had a strong
"viewed vs swiped" score but weak reach.
